## Study Planner v1.0.0: First release

A desktop study planner for Windows that keeps your courses, deadlines, tests
and timetable in one place.

### Features

* **Dashboard** with a personalised greeting, daily study goal, and countdowns
(days and hours) to upcoming tests and deadlines
* **Course Units**: add and remove your subjects, each with its own colour
* **Planner**: add deadlines, tests and study sessions using calendar and clock
pickers, and mark them done
* **Timetable**: weekly view of lectures, tutorials, labs and seminars
* **Progress** tracking for your units and tasks
* **Study Tips** by category, plus an optional tip of the day
* **Reminders** for deadlines, tests, lessons, session starts and 25-minute
break reminders
* **Settings**: dark/light theme, accent colour, UI scale, notification toggles

### Install

1. Download the installer below
2. Run it and follow the prompts
3. If Windows SmartScreen shows "Windows protected your PC", click
**More info**, then **Run anyway** (the installer is not code-signed)

### Your data

Stored locally in `.study_planner` in your user folder. Nothing is sent online.
